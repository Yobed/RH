# Plan: 02-04 Export journal de paie

<objective>
Permettre l'exportation des données de paie pour un mois donné (YYYY-MM) en format CSV/Excel avec les bonnes colonnes destinées au comptable.
</objective>

<tasks>

<task>
<description>Créer l'endpoint API de génération CSV Export.</description>
<read_first>
- app/api/paie/export/route.ts (nouveau)
- supabase/migrations/... (pour connaître structure `bulletins_paie` JSONB details)
</read_first>
<action>
1. Créer le handler HTTP `GET /api/paie/export` recevant `?periode=YYYY-MM`.
2. L'API doit filtrer sur les bulletins de l'entreprise courante à cette période, avec statut validé ou en_attente.
3. Générer un String CSV. Les colonnes standards : "Matricule, Nom, Salaire Brut, Heures Sup, Retenues CNPS, Retenues ITS, Retenues CMU, Charges Patronales, Salaire Net, Mode de paiement".
4. Mapper les données JSONB `details` et table `employees` dans les colonnes CSV. Renvoyer `text/csv`.
</action>
<acceptance_criteria>
- Endpoint GET répond avec un mimetype `text/csv`.
- La première ligne (Header) respecte le nom des colonnes requises.
- Les données de la base mappent au CSV sans null bytes ou format non reconnu.
</acceptance_criteria>
</task>

<task>
<description>Ajouter le bouton de téléchargement de l'export sur la page Liste des Paies.</description>
<read_first>
- app/(dashboard)/paie/page.tsx
- components/paie/PaieList.tsx
</read_first>
<action>
1. Sur la vue principale de Paie (la liste des bulletins ou bordereaux du mois sélectionné), ajouter une icône/bouton "Exporter CSV (Journal de Paie)".
2. Ce bouton appelle l'endpoint GET défini plus haut avec le `mois/annee` sélectionné du DatePicker ou de la Navbar interne.
</action>
<acceptance_criteria>
- L'interface inclut un bouton Download de type "Export Journal".
- Le clic déclenche un téléchargement de nom typique : "Journal_Paie_YYYY_MM.csv".
</acceptance_criteria>
</task>

</tasks>

<verification>
1. Vérifier que la génération de l'API est encodée en UTF-8 avec séparateurs conformes.
2. Tester le téléchargement direct côté client (`window.open` ou `download href blob`).
</verification>

<must_haves>

- L'export contient des détails clairs des cotisations (Net à payer, Brut et part patronale / salariale distinctes).
</must_haves>

# Plan: 02-01 Heures supplémentaires CI

<objective>
Implémenter la gestion des heures supplémentaires dans le moteur de paie (décret CI n°96-203), avec le calcul automatique des différentes majorations (+15%, +50%, +75%) et leur répercussion claire lors la génération d'un bulletin.
</objective>

<tasks>

<task>
<description>Ajouter la logique de majoration pour heures supplémentaires dans `lib/paie-ci.ts`.</description>
<read_first>
- lib/paie-ci.ts
- ROADMAP.md
</read_first>
<action>
1. Créer une fonction pure `calculerHeuresSup(nbH15: number, nbH50: number, nbH75: number, tauxHoraire: number)` dans `lib/paie-ci.ts` qui calcule séparément et additionne les 3 montants d'heures supplémentaires.
2. Mettre à jour `genererBulletinPaie` pour accepter un objet `heuresSup: { h15: number, h50: number, h75: number }` en paramètre (par défaut des zéros), l'ajouter au calcul du brut, et tracer ce montant dans les lignes du bulletin.
</action>
<acceptance_criteria>
- Une méthode `calculerHeuresSup` est exportée et gère les 3 paliers.
- `genererBulletinPaie` calcule le nouveau salaire brut en incluant le montant issu de `calculerHeuresSup`.
</acceptance_criteria>
</task>

<task>
<description>Mettre à jour l'UI (PaieDialog) et l'API (POST /api/paie) pour saisir et sauvegarder les heures supplémentaires.</description>
<read_first>
- components/paie/PaieDialog.tsx
- app/api/paie/route.ts
- (Supabase table definition `bulletins_paie` si nécessaire pour la modification JSON des détails)
</read_first>
<action>
1. Dans `PaieDialog.tsx`, ajouter des champs numériques optionnels (Inputs type "number") pour la saisie de : Heures +15%, +50%, et +75% dans le block des informations salariales (à l'édition/création).
2. Vérifier que la preview de la fiche de paie réagit et montre bien la ligne "Heures supplémentaires" et un montant calculé.
3. Dans `app/api/paie/route.ts` et `app/api/paie/[id]/route.ts` (si édition), s'assurer que les valeurs `heures_sup` soumises sont injectées dans la fonction `genererBulletinPaie` et stockées telles quelles dans le champ JSONB `details` du type `BulletinPaie` de Supabase.
</action>
<acceptance_criteria>
- L'utilisateur peut saisir un nombre d'heures majorées.
- Le brut et le net estimés dans la vue Preview du composant sont augmentés.
- Sauvegarder insère les variables `heures_sup` (h15, h50, h75) de l'employé dans les détails de `bulletins_paie`.
</acceptance_criteria>
</task>

</tasks>

<verification>
1. Compiler le code sans erreur TypeScript : `npx tsc --noEmit`.
2. Lancer les tests si appliqués à `lib/paie-ci.ts` : les heures supplémentaires calculées à taux horaire connu doivent retourner exactement le `tauxHoraire * ((h15 * 1.15) + (h50 * 1.5) + (h75 * 1.75))`.
</verification>

<must_haves>

- L'employeur doit pouvoir saisir 3 montants distincts d'heures (15%, 50%, 75%).
- L'ajout apparaît correctement dans les composants de traitement/JSONB de la base de données.
</must_haves>

# Phase 04 : Analytique RH & Reporting - Plan d'Implémentation 01

## 1. Objectif

Fournir aux gestionnaires RH des tableaux de bord analytiques globaux pour suivre :

- La pyramide des âges et les effectifs.
- Le suivi du turnover (entrées / sorties).
- Les statistiques basiques d'absentéisme et la masse salariale mensuelle.

## 2. État actuel

Nous disposons d'une table `employees` détaillée (âge, dates de contrat, genre), d'une table `paie` (rémunérations) et de `conges` (absences justifiées ou non). Le composant existant `MasseSalarialeDashboard.tsx` a été ébauché mais doit être consolidé et regroupé sur une page "Analytique".

## 3. Tâches techniques

### Tâche 1 : Aménager la structure de la page `/analytique`

- Créer le dossier et le fichier `app/(dashboard)/analytique/page.tsx`.
- Intégrer des cartes (KPIs) avec les statistiques principales calculées côté serveur :
  - Nombre total d'employés actifs.
  - Ancienneté moyenne des employés.
  - Recrutements (entrées) & départs de l'année.

### Tâche 2 : Création des Graphiques (Recharts / UI)

- **Pyramide des âges & ratio de genre :** Répartir les employés dans des tranches d'âges (18-25, 26-35, 36-45, 46-55, 55+).
- **Masse salariale :** Regrouper les montants bruts des fiches de paie par mois sur les 12 derniers mois.
- **Turnover :** Afficher un bar chart des arrivées vs départs (embauches vs fins de contrats/démissions) par mois.

### Tâche 3 : Intégration et requêtes API Supabase

- Mettre en place les requêtes SQL (ou via le client JS de Supabase) dans le Server Component `/analytique/page.tsx` pour l'agrégation des données.
- S'assurer du filtrage RLS (`company_id`).
- Respecter les contraintes de performance (mise en cache fine ou chargement asynchrone / Suspense si nécessaire).

## 4. Tests et validations

- Vérifier que seules les données de l'entreprise connectée s'affichent.
- S'assurer qu'un employé en statut "inactif" est bien compté dans les départs, mais ignoré du décompte des employés actifs de l'instant T.
- Vérifier les graphiques sur affichage mobile (responsive Recharts).

**Partie A — app/(dashboard)/employes/[id]/page.tsx:**

L'onglet Contrats est un Server Component — il ne peut pas contenir de logic client. Pour ajouter le bouton "Renouveler", le plus simple est de convertir la ligne contrat en un petit Client Component `ContractRenewButton`:

Creer `components/rh/ContractRenewButton.tsx` — "use client":
```typescript
"use client";
import { ContractDialog } from "@/components/rh/ContractDialog";
import type { Tables } from "@/types/supabase";

type Contract = Tables<"contracts">;
type Employee = Tables<"employees">;

export function ContractRenewButton({ contract, employee }: { contract: Contract; employee: Employee }) {
  if (contract.type_contrat !== "CDD") return null;
  return (
    <ContractDialog
      employee={employee}
      renewFrom={contract}
      triggerLabel="Renouveler"
    />
  );
}
```

Note: ContractDialog doit accepter un `triggerLabel?: string` prop pour personnaliser le texte du bouton trigger — ajouter cette prop dans le Task 1 si pas deja fait, ou gerer directement dans ContractRenewButton via le pattern Dialog de @base-ui.

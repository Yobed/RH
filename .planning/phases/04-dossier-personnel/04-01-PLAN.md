# Plan 04-01 : GED légère & Pagination

**Module :** Archives (`app/(dashboard)/archives`)
**Objectif :** Transformer la page des archives en un gestionnaire documentaire performant capable de gérer des centaines de documents avec recherche et filtrage.

---

## 1. Contexte & Backend

La table `documents` est déjà en place avec les colonnes nécessaires (`id`, `name`, `famille`, `employee_id`, `file_url`).
Actuellement, la page archives est limitée à 20 documents (`.limit(20)`).

**Changements structurels :**
- Passer d'un fetch unique à une pagination côté serveur (optionnel pour la v1, le client-side peut suffire pour < 200 docs, mais nous allons prévoir le filtrage Supabase).
- Ajouter le support du filtrage par `employee_id` et `famille` dans les requêtes.

---

## 2. Développement UI (`app/(dashboard)/archives/page.tsx`)

### Étape 2.1 : Barre de recherche et filtres
Ajouter un composant de contrôle au-dessus du tableau :
- `Input` pour la recherche par nom (debounced search).
- `Select` pour filtrer par **Famille** (Contrat, Paie, Médical, etc.).
- `Select` (ou Combobox) pour filtrer par **Employé**.

### Étape 2.2 : Pagination logicielle
- Utiliser un état local pour `page` et `itemsPerPage` (défaut 10).
- Calculer dynamiquement les index pour l'affichage.

### Étape 2.3 : Interface de la table
- Améliorer le rendu visuel du tableau (Design Premium).
- Ajouter des tooltips pour les noms de fichiers longs.
- Ajouter une action "Supprimer" (avec confirmation).

---

## 3. Composants requis

- **`DocumentSearchFilters`** : Composant client pour gérer les états des filtres.
- **`PaginationControls`** : Boutons Suivant/Précédent avec indicateur de page.
- **`EmptyState`** : État visuel quand aucun document ne correspond aux filtres.

---

## 4. Vérification (UAT)

1. [ ] La recherche d'un document par son nom filtre la liste en temps réel.
2. [ ] Le passage d'une famille à une autre (ex: "Contrat") affiche uniquement les documents concernés.
3. [ ] La pagination permet de naviguer entre les blocs de documents (si > 10 docs).
4. [ ] Le lien "Ouvrir" ouvre le fichier dans un nouvel onglet via l'URL Supabase.
5. [ ] La suppression d'un document le retire de la base de données.

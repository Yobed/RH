Créer components/paie/SageImportDropzone.tsx en adaptant le pattern de DocumentUploadDialog.tsx.

Ce composant est autonome (pas de props requises). Il gère en interne :

ÉTAT :
```typescript
const [file, setFile] = useState<File | null>(null);
const [periode, setPeriode] = useState<string>(() => {
  const now = new Date();
  return `${now.getFullYear()}-${String(now.getMonth() + 1).padStart(2, "0")}`;
});
const [loading, setLoading] = useState(false);
const [result, setResult] = useState<{ imported: number } | null>(null);
const [errors, setErrors] = useState<Array<{ row: number; message: string }>>([]);
const fileRef = useRef<HTMLInputElement>(null);
```

HANDLERS :
- handleDrop(e) : e.preventDefault() → setFile(e.dataTransfer.files?.[0] ?? null) → reset result/errors
- handleFileChange(e) : setFile(e.target.files?.[0] ?? null) → reset result/errors
- handleRemoveFile() : setFile(null) → reset result/errors
- handleDownloadTemplate() : window.location.href = "/api/paie/import-sage/template"
- handleImport() : 
  1. if (!file) { toast.error("Sélectionnez un fichier .xlsx") ; return }
  2. setLoading(true)
  3. const fd = new FormData() → fd.append("file", file) → fd.append("periode", periode)
  4. const res = await fetch("/api/paie/import-sage", { method: "POST", body: fd })
  5. const json = await res.json()
  6. if (json.success) { setResult({ imported: json.imported }); setErrors([]); toast.success(`${json.imported} ligne(s) importée(s) avec succès`) }
  7. else { setErrors(json.errors ?? []); setResult(null); toast.error("Des erreurs ont été détectées dans le fichier") }
  8. setLoading(false)

UI SECTIONS (dans l'ordre, style Tailwind cohérent avec les pages paie) :

1. Bouton "Télécharger le template" :
   - variant="outline", icon ArrowLineDown de @phosphor-icons/react
   - onClick={handleDownloadTemplate}
   - Texte : "Télécharger le template Excel"

2. Sélecteur de période :
   - Label : "Période d'import (YYYY-MM)"
   - Input type="month" value={periode} onChange → setPeriode
   - Classe : "w-48"

3. Zone drag-and-drop :
   - div avec onDrop={handleDrop} onDragOver={(e) => e.preventDefault()}
   - Style : border-2 border-dashed rounded-lg p-8 text-center cursor-pointer
   - Si file non null : afficher nom du fichier + bouton X (handleRemoveFile)
   - Si file null : icône Upload + texte "Glissez votre fichier .xlsx ici ou cliquez pour sélectionner"
   - onClick sur la zone (si file null) : fileRef.current?.click()
   - Input caché : ref={fileRef}, type="file", accept=".xlsx", onChange={handleFileChange}, className="hidden"

4. Bouton "Importer" :
   - disabled={!file || loading}
   - onClick={handleImport}
   - Si loading : <Loader2 className="animate-spin" /> + "Traitement en cours..."
   - Sinon : texte "Importer"

5. Résultat succès (si result) :
   - Card verte avec CheckCircle icon et "{result.imported} ligne(s) importée(s) avec succès"

6. Liste d'erreurs (si errors.length > 0) :
   - Card rouge avec titre "Erreurs détectées ({errors.length})"
   - Liste ul/li pour chaque erreur : "Ligne {e.row} : {e.message}"
   - Texte d'aide : "Corrigez ces erreurs dans votre fichier et réimportez."

Imports nécessaires : useState, useRef de react ; toast de sonner ; Button, Card de shadcn/ui ;
ArrowLineDown, Upload, CheckCircle, X, Spinner (ou Loader2 de lucide-react) de @phosphor-icons/react ou lucide-react.

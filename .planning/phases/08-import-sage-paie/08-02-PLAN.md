Créer app/api/paie/import-sage/route.ts en adaptant le pattern de app/api/import/employees/route.ts.

Logique complète à implémenter dans l'ordre strict :

1. AUTH : createServerClient() → getUser() → 401 si absent
2. PROFILE : .from("profiles").select("company_id").eq("id", user.id).single() → 400 si company_id absent
3. PARSE FORM : formData.get("file") → 400 si absent
4. READ XLSX : XLSX.read(buf, { type: "array" }) → wb.Sheets[wb.SheetNames[0]] → sheet_to_json (sans header param, defval: "")
5. CHECK VIDE : rows.length === 0 → 400
6. LIMITE : rows.length > 1000 → 422 { success: false, errors: [{ row: 0, message: "Le fichier contient plus de 1000 lignes. Importez par tranches de 1000 lignes maximum." }] }
7. VALIDATION COLONNES : validateRequiredColumns(REQUIRED_COLUMNS, rows[0]) → si non-null, retourner 422 { success: false, errors: [{ row: 0, message: <résultat> }] }
8. VALIDATION LIGNE PAR LIGNE : pour chaque row (index i, rowNum = i+2) :
   - employeeId = String(row["Matricule/Nom"] ?? "").trim() — si vide → erreur "Ligne N: Matricule/Nom vide"
   - baseSalary = parseNumericFR(row["Salaire de base"]) — si null → erreur "Ligne N: 'Salaire de base' non numérique"
   - netPay = parseNumericFR(row["Net A Payer"]) — si null → erreur "Ligne N: 'Net A Payer' non numérique"
   - Si valide : push dans toInsert
9. SI errors.length > 0 : retourner 422 { success: false, errors } SANS aucun insert
10. INSERT : supabase.from("payroll_logs").insert(toInsert) — si insertError → 500 { error: insertError.message }
11. SUCCÈS : 200 { success: true, imported: toInsert.length, errors: [] }

Chaque objet dans toInsert :
```typescript
{
  company_id: profile.company_id,
  employee_id: employeeId,
  base_salary: baseSalary,
  net_pay: netPay,
  periode: periodeFromForm ?? null,  // voir note ci-dessous
  import_source: "sage" as const,
  imported_at: new Date().toISOString(),
  imported_by: user.id,
}
```

Note sur `periode` : lire la valeur optionnelle depuis formData.get("periode") — si présente et au format YYYY-MM, l'utiliser. Sinon null. Cela permet à l'UI d'envoyer la période sélectionnée.

Anti-patterns à éviter absolument :
- NE PAS utiliser header: 7 dans sheet_to_json (le template SIRH a les en-têtes en ligne 1)
- NE PAS utiliser SUPABASE_SERVICE_ROLE_KEY — createServerClient() uniquement
- NE PAS écrire partiellement (transaction applicative : si errors.length > 0, retour immédiat sans insert)
- NE PAS utiliser `any` TypeScript

    Créer `app/(dashboard)/conges/calendrier/page.tsx` (Server Component, `export const dynamic = 'force-dynamic'`) :

    1. Récupérer les congés du mois courant (ou passé en `searchParams.mois`) :
       ```typescript
       const mois = searchParams?.mois ?? new Date().toISOString().slice(0, 7) // "YYYY-MM"
       const debut = `${mois}-01`
       const fin = dernier jour du mois (calculer avec Date)
       ```
    2. Requête Supabase :
       ```typescript
       const { data: conges } = await supabase
         .from("conges")
         .select(`id, employee_id, type, date_debut, date_fin, nb_jours, statut,
                  employees(full_name, departement)`)
         .lte("date_debut", fin)
         .gte("date_fin", debut)
         .in("statut", ["approuve", "valide_manager", "en_attente"])
         .order("date_debut")
       ```
    3. Transformer en `CongeCalendrierItem[]` — extraire `employees.full_name` et `employees.departement`.
    4. Extraire la liste distincte des départements non-null.
    5. Rendre `<CongesCalendrierClient conges={...} departements={...} moisInitial={mois} />`.
    6. Ajouter un bouton de retour vers `/conges` dans le header de la page.
    7. `export const metadata = { title: "Calendrier des Absences — RH Manager CI" }`.
  </action>
